# NORTH/FORM — Visual Reference Instructions for Codex

Inspect every image in this folder before proposing or implementing any further visual redesign.

These references are not to be copied literally. Extract the visual principles:

- aggressive editorial typography
- strict architectural grids
- overlapping image/type composition
- architectural imagery treated as layout, not card content
- large visual masses
- controlled asymmetry
- restrained palette
- 3D/geometry integrated into composition rather than isolated as a demo
- minimal UI chrome
- strong contrast between dense and open sections
- portfolio/case-study feeling rather than generic agency sections

Important:
- Do not reproduce logos, copy, branding, or exact layouts.
- NORTH/FORM must remain its own brand.
- Build the static composition first.
- 3D and parallax are enhancements, not substitutes for composition.
- Preserve accessibility, progressive enhancement, reduced-motion support, and WordPress architecture.
- Do not implement ACF yet.

Before changing code, return:
1. What you learned from each reference image.
2. The visual rules you will transfer to NORTH/FORM.
3. A concrete hero composition with approximate viewport proportions.
4. A concrete project/case-study composition system.
5. How the 3D element integrates into the hero without becoming a separate demo section.
